## 背景

- MetaNutri 生态：**MetaNutri-AI**（主仓，全栈平台）· **ppgr-predictor**（子仓，PPGR 血糖预测）· **Nutri-RAG**（本仓，生态的 LLM/RAG 模块）。
- 生态内已有论文：PPGR 测量可靠性跨队列比较研究（medRxiv 预印本，Elijah Zhao 一作，29 页）。**本仓库与该论文相互独立**：论文代码指向 MetaNutri `research/`，全文无 RAG/LLM 内容；本仓 README 定位为"MetaNutri 生态的 RAG 模块"，不声称属于该论文。

## 现有研究素材（可支撑论文骨架）

- 数据管线：325 食物 × 32 营养项 + 17 段膳食指南切片 = 342 chunks（ChromaDB），脚本可复现
- RAG 管线：均衡双路检索 + 生成带引用溯源（qwen-plus）
- 评测：50 题全 100%（消融前 88%）、命中/忠实双指标
- 拒答评测：10 条边界/无关题，100% 正确拒答（防幻觉验证）
- 超参数消融：top-k × 阈值 9 组扫描，定稿 top-k=5
- 混合检索对比：纯向量 vs 混合，诚实负结果（纯向量已饱和）
- 失败归因：6 条裸 LLM 错误定性分析（精度损失/区域错位/立场混合/框架替代）
- 工程闭环：CI 三 job 全绿、26 项测试、线上 demo、中英双语界面、评测研究面板

## 对标 PPGR 论文的差距（诚实评估）

| PPGR 论文具备 | Nutri-RAG 现状 | 差距 |
|---|---|---|
| 外部公开数据集（CGMacros 45 受试者/1557 餐） | 公开官方数据，但仅 342 切片小语料 | 规模弱一档 |
| 严格验证协议（LOPO 受试者级） | 50 题自建评测 + 拒答 + 消融 + 混合对比 | **自建评测集无外部 benchmark 对照** |
| 聚焦的研究问题/方法论主张 | 标准 RAG 管线 + 认真评测，**未提出新方法/基准/协议** | 差在"提出"这一步 |
| 完整闭环可复现 | 全可复现 + CI + demo | 本项反而更强 |

**结论**：当前版本够写技术报告（arXiv 级别），但含金量低于 PPGR 论文；以研究论文标准尚缺一个"新贡献"。

## 若升级到论文级，三个可选方向（任选其一）

1. **中文营养问答评测基准**：将 50+10 题扩展为带构建标准、类别分层、双盲打分协议的公开评测集——数据集/评测贡献。
2. **拒答协议方法论**：把"边界题拒答 + 判定"形式化为可复用的防幻觉评测协议。
3. **小语料检索策略研究**：以消融 + 混合对比为核心，补 BM25/其他 embedding 对照，形成"小领域语料下检索策略选择"的研究叙事。

## 路线决策（2026-10-29，已拍板）

**方向**：NutriQA——中文官方营养数据上的可溯源 RAG 问答评测基准 + 跨模型实证研究。综合原方向 1+2：拒答评测并入基准第四类；检索策略作为实证组成部分（不单独立论）。

**论文叙事**（arXiv 技术报告级）：三个贡献——
1. **基准**：~200 题开放问答（数值/指南/禁忌/拒答四类），gold 全部官方可溯源，含评分协议；
2. **实证发现**：跨模型 × 配置（RAG/无 RAG/指令）对比——数值精确性、引用可溯源核验、检索边界 vs 提示词拒答差异；
3. **可复现系统**：数据→管线→评测→CI 全脚本化（现成资产）。

**规模**：先 **200 题**（S1 完成），后续可升 **300 题**（含专家复核，更硬）。

**跨模型清单**：qwen-plus（必有）＋ **DeepSeek** ＋ 火山引擎第三模型（**待选**，2026-10-29 由用户后续指定）。

**执行阶段**：
- S1 基准扩充：50→200 题，四类分类学 + 构建标准（1-2 周）
- S2 协议与校验：LLM-as-judge vs 人工标注一致性（30-50 条对照）、拒答分类学、引用核验器（1 周）
- S3 跨模型实验：3 模型 × 3 配置 + 检索策略对照（3-4 周，API 成本可控）
- S4 论文：技术报告 → arXiv（2 周）

**闸门**：S2 的 judge-人工一致性 ≥ 0.8 为 go/no-go；不达标降级为"技术报告 + 基准"（仍可发 arXiv）。

**空白点依据**（2026-10-29 检索核验）：FoodSky CDE-12K（中国营养师考试多选题）、NGQA（英文图谱推理）均不覆盖中文开放问答 + 引用溯源 + 数值精确性；UAEval4RAG / ScopeQA / NoMIRACL 为通用不可问答评测框架，非领域特定。
